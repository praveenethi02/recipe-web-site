The aim 01: Define strict TypeScript interfaces for all DummyJSON API responses
Actual prompt: I am building a Vue 3 + TypeScript SPA that fetches from https://dummyjson.com/recipes. Generate strict TypeScript interfaces (no 'any') for the following API responses: GET /recipes (paginated list), GET /recipes/:id (single recipe), POST /auth/login (JWT response), and a CartItem shape for a meal-planner feature. Include all fields from the DummyJSON docs.

The aim 02: Build the API composable with full error handling and loading state
Actual prompt: Create a Vue 3 Composition API composable called useRecipeApi.ts that wraps fetch() calls to DummyJSON. It should expose: fetchRecipes(skip, limit), searchRecipes(query, skip, limit), fetchRecipeById(id), fetchRecipesByMealType(type). Each function should set a shared `loading` ref to true while in-flight and write any errors to an `error` ref. All return types must use the interfaces from types/index.ts. No 'any'.
